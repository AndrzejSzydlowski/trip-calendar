# 🧳 Календарь поездок

Веб-приложение для планирования и отслеживания поездок на календаре —
с ролями пользователей, 2FA для суперпользователя и историей изменений.

## Возможности

- Месячный вид календаря с подсветкой сегодняшнего дня
- Добавление / редактирование / удаление поездок (название, место, даты, цвет, заметки)
- **Роли пользователей:**
  - **Суперпользователь** (один) — вход по паролю + код-подтверждение на
    email (2FA), приглашает/удаляет пользователей, меняет роли
  - **Редактор** — чтение и правка поездок
  - **Читатель** — только чтение
- **История изменений** — кто, когда и что изменил в каждой поездке
  (ведётся триггером в базе, подделать из браузера нельзя)
- Живое обновление календаря у всех участников (realtime)
- Поддержка тёмной темы, адаптивная вёрстка

## Архитектура

Статический фронтенд (HTML/CSS/JS без сборки) + [Supabase](https://supabase.com)
в роли бэкенда: Postgres с Row Level Security, Auth, Edge Functions для
2FA и управления пользователями.

```
index.html, style.css, app.js   — фронтенд (открывать как есть, деплой на GitHub Pages)
config.js                        — публичные SUPABASE_URL / anon key
supabase/migrations/             — схема БД, роли, RLS, триггер аудита
supabase/functions/              — Edge Functions: 2FA-коды, приглашения, роли
supabase/README.md               — пошаговая настройка бэкенда
```

## Быстрый старт

1. Настройте бэкенд по инструкции в [`supabase/README.md`](supabase/README.md)
   (создать проект, применить миграцию, задеплоить функции, вписать ключи в `config.js`).
2. Откройте `index.html` в браузере либо поднимите локальный сервер:
   ```bash
   npx serve .
   ```
3. Войдите под суперпользователем (создаётся вручную в Supabase — см.
   инструкцию), подтвердите код из письма, пригласите остальных участников.

## Деплой фронтенда на GitHub Pages

1. Settings → Pages → Source: `Deploy from a branch`
2. Branch: `main`, папка `/ (root)`
3. Сохранить — сайт появится по адресу `https://<username>.github.io/<repo>/`
4. Укажите этот адрес как Site URL в настройках Supabase Auth (см. `supabase/README.md`, шаг 6).

## Стек

HTML / CSS / JavaScript (ES-модули, без сборки) + Supabase (Postgres, Auth,
Edge Functions, Realtime). Письма с кодами 2FA отправляются через Resend.
