# 🧳 Календарь поездок

Простое веб-приложение для планирования и отслеживания поездок на календаре.

## Возможности

- Месячный вид календаря с подсветкой сегодняшнего дня
- Добавление / редактирование / удаление поездок (название, место, даты, цвет, заметки)
- Поездки отображаются как цветные метки на днях календаря
- Боковая панель: ближайшие поездки и полный список
- Данные сохраняются в `localStorage` браузера — бэкенд не требуется
- Поддержка тёмной темы (следует системным настройкам)
- Адаптивная вёрстка для мобильных устройств

## Запуск

Это статический сайт без сборки — просто откройте `index.html` в браузере,
либо поднимите локальный сервер:

```bash
npx serve .
```

## Деплой на GitHub Pages

1. Settings → Pages → Source: `Deploy from a branch`
2. Branch: `main`, папка `/ (root)`
3. Сохранить — сайт появится по адресу `https://<username>.github.io/<repo>/`

## Стек

Чистый HTML / CSS / JavaScript, без зависимостей и шагов сборки.
